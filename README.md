# busy-wait-energy

Artefact for the paper **"BEAM Scheduler Busy-Waiting and Energy Measurement"**
(MIPRO, Software and Systems Engineering; in preparation).

The BEAM virtual machine (Erlang, Elixir, Gleam) lets idle schedulers busy-wait by default.
This repository holds everything needed to check and repeat the paper's measurements of that
effect: web servers with busy-waiting on and off, as Docker containers and as native processes,
under static HTTP, dynamic HTTP and WebSocket workloads.

## Status

Work in progress. Measurements are taken with the framework
[BEAM-web-server-benchmarks](https://github.com/joegharbi/BEAM-web-server-benchmarks)
(WSEB), branch `controlled-measurements`; the exact commit used for each campaign is recorded
here and in each campaign's `metadata.json`.

## Layout

| Folder | Contents |
|---|---|
| `campaigns/` | The campaign config files used for the paper |
| `evidence/` | Per campaign: CSVs, summaries, `metadata.json`, configs (raw Scaphandre logs are kept separately, see below) |
| `analysis/` | Scripts that turn the evidence into the paper's tables and numbers |
| `figures/` | The paper's figures, generated by `analysis/` |

Raw Scaphandre logs are large; where they are archived is noted per campaign in `evidence/`.
